# Procedimientos de atención al cliente

Este documento reúne los procedimientos operativos paso a paso. Cada procedimiento indica qué necesita el cliente, qué hace el equipo y en qué plazos.

## Procedimiento de devolución de un producto
1. El cliente solicita la devolución indicando el número de pedido (por ejemplo `PED-1042`) y el motivo.
2. El asistente verifica que el pedido esté dentro de los **30 días corridos** desde la entrega (ver *Política de devoluciones*).
3. Se genera un ticket de devolución con número de seguimiento.
4. Logística coordina el retiro sin cargo dentro de las **72 horas hábiles**.
5. Control de calidad revisa el producto en **5 días hábiles** y, aprobada la revisión, se emite el reembolso por el medio de pago original.

## Procedimiento ante un producto que llegó dañado
1. El cliente reporta el daño idealmente con una **foto del producto** y el número de pedido.
2. Si el reporte ocurre dentro de las **48 horas** de la entrega, se trata como daño de transporte: no aplica el análisis de garantía.
3. Se genera un ticket de reclamo y el cliente elige **reposición sin cargo** o **reembolso total**.
4. El retiro del producto dañado se coordina junto con la entrega de la reposición.

## Procedimiento de reclamo por demora en la entrega
1. El cliente consulta el estado de su pedido; si figura **demorado**, puede dejar un reclamo formal.
2. El reclamo genera un ticket con prioridad de logística.
3. Logística responde en un máximo de **24 horas hábiles** con una nueva fecha estimada.
4. Si la demora supera los **7 días hábiles** sobre el plazo original, el cliente puede optar por la cancelación con reembolso total, incluido el envío.

## Procedimiento de gestión de garantía
1. El cliente describe la falla y aporta el número de pedido o de serie.
2. Se verifica que el producto esté dentro del plazo de garantía (ver *Garantías*).
3. Se genera un ticket de garantía y se coordina el envío del producto al servicio técnico, sin cargo.
4. El diagnóstico demora hasta **10 días hábiles**; según el resultado se repara, se repone o se reembolsa.

## Procedimiento de cambio de dirección de entrega
1. Solo puede solicitarse mientras el pedido esté **en preparación** (antes del despacho).
2. El cliente indica la nueva dirección completa.
3. Si el pedido ya fue despachado, se espera el primer intento de entrega fallido y se coordina la reprogramación con el transportista.

## Procedimiento de facturación
1. El cliente puede pedir la factura de cualquier pedido indicando su número.
2. Si necesita cambiar los datos fiscales, el plazo es de **72 horas** desde la compra (ver *Pagos y facturación*).
3. La factura se reenvía por correo electrónico dentro de las 24 horas.
